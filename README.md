# Point Cloud Viewer (点云展示与分析平台)

基于 React 19、Tailwind CSS 4 与 Three.js 构建的高性能 3D 点云可视化与切分分析平台。支持大型 TXT 点云文件流式解析、Z 轴高度彩虹色谱渲染、多项目管理、自由/定向切分、平面投影以及点密度直方图统计。

---

## 🚀 平台用途与核心功能

本平台旨在为三维视觉研究人员、测绘工程师及点云数据爱好者提供一个轻量、高效、开箱即用的 Web 端点云交互分析工具。

| 核心模块 | 功能说明 |
| :--- | :--- |
| **大型点云导入** | 支持 `.txt`、`.xyz`、`.pts`、`.csv` 格式，内置异步流式分块解析器，可轻松导入数百万点的海量点云数据并显示实时加载进度。 |
| **彩色渲染系统** | 完美支持带有 RGB 颜色或仅有 XYZ 坐标的点云；无 RGB 时自动根据 Z 轴高度进行平滑的彩虹色谱（蓝-青-绿-黄-红）映射。 |
| **3D 交互控制** | 基于 Three.js 的流畅视角操作：左键旋转、右键平移、滚轮缩放，支持一键锁定当前视角及多角度预设（ISO / 正视 / 俯视 / 侧视）。 |
| **项目管理系统** | 支持多项目列表管理，可在不同项目间独立切换点云数据、新建空白项目或重命名/删除项目。 |
| **点云均匀切分** | 支持沿 X、Y、Z 轴将点云均匀切分为 2~50 份，提供切分平面可视化，支持整体查看或逐片独立观察。 |
| **平面投影与直方图** | 支持将整体或切片点云投影至 XY、XZ、YZ 平面；提供基于最近邻中位数的自适应网格点密度直方图统计与热力图渲染。 |

## 📦 下载与打开方式

### 1. 克隆代码库
通过 Git 克隆项目到本地：
```bash
git clone https://github.com/sunximing19-tech/pointcloud-viewer.git
cd pointcloud-viewer
```

### 2. 安装依赖并启动
本项目依赖 Node.js 与 pnpm 包管理器：
```bash
# 安装依赖
pnpm install

# 启动本地开发服务器
pnpm dev
```
启动成功后，在浏览器中打开终端显示的本地链接（通常为 `http://localhost:3000`）即可使用。

## 🎨 点云案例展示

平台内置了一键加载的**综合几何体演示场景**（包含球体、地面、垂直圆柱及斜坡），无需准备本地文件即可快速体验全部功能：

1. **点击左侧边栏的 "加载示例数据" 按钮**。
2. 平台将自动生成包含约 5,000 个点的混合几何体点云，并以彩虹高度色谱渲染。
3. 您可以在右侧 3D 视图中进行旋转、缩放、切换 Z 轴切分（如切分 4 份并单片查看），或在底部面板添加点密度直方图与平面投影。

- **样式方案**：Tailwind CSS 4, Lucide Icons
- **3D 渲染**：Three.js
- **UI 组件**：Radix UI / shadcn/ui 风格定制组件
